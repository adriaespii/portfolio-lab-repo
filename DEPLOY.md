# Despliegue en GitHub Pages

Para activar GitHub Pages y obtener la URL pública:

1. Ve a **Settings → Pages** de este repositorio:
   https://github.com/adriaespii/portfolio-lab-repo/settings/pages

2. En la sección **Build and deployment**:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`

3. Haz clic en **Save**.

4. Espera unos minutos a que GitHub construya y despliegue el sitio.

5. La URL pública será:
   👉 **https://adriaespii.github.io/portfolio-lab-repo/**

---

**Nota:** Este archivo es solo un recordatorio del paso manual necesario. Una vez activado Pages, puedes borrar este archivo si lo prefieres.
